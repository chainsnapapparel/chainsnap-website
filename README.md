## Publishing with GitHub Pages

1. Open the ChainSnap website repository on GitHub.
2. Go to **Settings**.
3. Select **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.
8. Wait for GitHub to publish the website.

Your website should then be available at:

`https://YOUR-GITHUB-USERNAME.github.io/chainsnap-website/`

## Connecting the custom domain

The domain is:

`chainsnapapparel.com`

Once GitHub Pages is working:

1. Open your repository's **Settings → Pages**.
2. Enter `chainsnapapparel.com` under **Custom domain**.
3. Save the change.
4. Open your GoDaddy DNS settings.
5. Add the DNS records recommended by GitHub Pages.
6. Return to GitHub Pages and enable **Enforce HTTPS** once it becomes available.

DNS changes can take some time to update.
